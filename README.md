# UNIT 2: C++ Programming Assignment #2
This folder contains C++ source-code examples for all five assignment questions.

## Files
- `Q1_AND.cpp` — Bitwise AND
- `Q1_OR.cpp` — Bitwise OR
- `Q1_XOR.cpp` — Bitwise XOR
- `Q1_LeftShift.cpp` — Left shift
- `Q1_RightShift.cpp` — Right shift
- `Q2_GradeValidation.cpp` — Validate marks from 0 to 100
- `Q3_EntryRequirement.cpp` — Conditional logic using age and ID
- `Q4_BasicCalculator.cpp` — Calculator using a switch statement
- `Q5_ForLoop.cpp` — Example of a for loop
- `Q5_WhileLoop.cpp` — Example of a while loop
- `Q5_DoWhileLoop.cpp` — Example of a do-while loop

## How to run
1. Download or copy the required `.cpp` file.
2. Open it in Visual Studio Code.
3. Compile and run it using a configured C++ compiler (such as g++).
4. Each `.cpp` file has its own `main()` function, so compile and run one file at a time.
